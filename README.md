# The Claude Handbook

A three-level guide to Claude: install and use it, run Claude Code and connect tools, and understand how MCP works inside.

Open `index.html` in a browser. It is one self-contained file.

| Level | Covers |
|---|---|
| Beginner | What Claude is, installing the desktop app, first prompts, app features, other frontier models |
| Intermediate | Claude Code in the terminal, how the agent loop works, CLAUDE.md, skills, subagents, hooks, connectors, plugins vs connectors |
| Advanced | MCP roles, how a tool is defined, how Claude uses a tool step by step, where tools run, MCP vs API, connecting your own app, automation |

Facts were checked against official docs on 14 Oct 2026; product details change, so check the linked sources before relying on them.

`src/handbook.src.html` is the editable source (the hand-drawn font is inlined into `index.html` at build time).

Diagrams are drawn with [rough.js](https://roughjs.com) in the Excalidraw style, using the Virgil font from [Excalidraw](https://github.com/excalidraw/excalidraw) (SIL Open Font License).
